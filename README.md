# second-brain-app

Persoonlijk Second Brain systeem (Next.js) — notities, gesprekken, herinneringen.

## Features

- Note-taking with markdown support
- Conversation logging
- Memory/knowledge graph
- Full-text search
- Tag-based organization

## Installation

```bash
git clone https://github.com/hmol33/second-brain-app.git
cd second-brain-app
npm install
npm run dev
```

## Usage

Access at `http://localhost:3000` after starting the development server.
